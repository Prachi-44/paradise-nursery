# Paradise Nursery

Paradise Nursery is an online houseplant shopping application built with React.

## Features
- Browse houseplants by category.
- View plant names, images, and prices.
- Add plants to the shopping cart.
- Increase or decrease item quantities.
- Remove plants from the cart.
- View the cart total and continue shopping.

## Technologies
- React
- Redux Toolkit
- React Router
- CSS
