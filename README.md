# 🌿 Paradise Nursery

**Paradise Nursery** is an online houseplant shopping application designed to help plant lovers discover and purchase beautiful indoor plants for their homes and workspaces.

## 🌱 About the Project

Paradise Nursery provides a simple and user-friendly shopping experience where customers can explore houseplants by category, view plant details, and manage their shopping cart.

The application is built using React and Redux Toolkit to provide an interactive interface and efficient cart management.

## ✨ Features

- **Welcome Landing Page:** Introduces Paradise Nursery and provides a Get Started button.
- **Plant Categories:** Browse houseplants organized into different categories.
- **Plant Details:** View plant images, names, and prices.
- **Add to Cart:** Add selected plants to the shopping cart.
- **Cart Management:** Increase or decrease plant quantities and remove items.
- **Dynamic Cart Count:** Displays the number of items in the cart.
- **Price Calculation:** Automatically calculates item totals and the overall cart total.
- **Continue Shopping:** Navigate back to the plant listing.
- **Responsive Design:** A clean shopping interface for different screen sizes.

## 🚀 Getting Started

### Prerequisites

Install Node.js and npm on your computer.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Prachi-44/paradise-nursery.git
   ```

2. Navigate to the project directory:

   ```bash
   cd paradise-nursery
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.
